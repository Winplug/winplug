# WinPlug

WinPlug is a Mac app that brings back your Windows habits: a taskbar, Alt-Tab between windows, a snipping tool, Ctrl shortcuts, window snapping and more. It is made for people switching from Windows to a Mac.

**Website and download:** https://winplug.app

This repository holds the release notes and the public issue tracker. WinPlug's source code is not published.

## What it does

| Module | What you get |
|---|---|
| WinPlug Taskbar | A taskbar with window previews, a Start menu and a notification center |
| WinPlug Snap | A snipping tool on Win + Shift + S, with an editor |
| WinPlug Keyboard | Ctrl + C, Ctrl + V, Alt + F4 and other Windows shortcuts, on any keyboard layout |
| WinPlug Switch | Alt-Tab between windows, with thumbnails and search |
| WinPlug Explorer | A file explorer with tabs, an address bar, a dual pane, cut and paste |
| WinPlug Capture | A screen recorder with an editor |
| WinPlug Clipboard | A clipboard history on Ctrl + Alt + V |
| WinPlug Layout | Window snapping by dragging or with Win + arrow keys |
| WinPlug Mouse | Scroll direction for the mouse only, side buttons, Ctrl + wheel zoom |

WinPlug is not an emulator and does not run Windows software.
